# v0.2 MVP Complete

Complete phoenix-feed from skeleton compiles to a runnable v0.2 MVP:

- Read API for active incidents and single incident detail.
- Unit and lifecycle history persistence.
- Contract canary checks.
- Janitor raw-retention sweep.
- Vanilla Leaflet web client.
- Paid history placeholder.
- Health endpoint with data freshness.

OpenSpec CLI note: the requested change id contains a dot. `openspec new change v0.2-mvp-complete` fails under OpenSpec 1.2.0 because change names may only contain lowercase letters, numbers, and hyphens. This directory is the equivalent OpenSpec change package at the owner-requested path.
